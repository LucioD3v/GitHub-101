# GitHub-101

Curso práctico para aprender lo esencial de GitHub mediante ejercicios guiados. No necesitas experiencia previa programando.

## Elige tu idioma

- [Español](docs/es/README.md)
- [English](docs/en/README.md)
- [Português](docs/pt/README.md)

## Qué aprenderás

Crear repositorios, realizar commits, trabajar con ramas, organizar tareas con Issues, abrir y revisar pull requests y fusionar cambios.

## Preparación para certificación

Cada curso incluye preguntas originales de repaso con respuestas explicadas. No son preguntas oficiales ni una certificación. Cuando definamos qué certificación preparar, podremos relacionar las lecciones con sus objetivos públicos y ampliar el banco de práctica.
