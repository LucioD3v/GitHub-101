# Cómo contribuir / How to contribute

## Español

El contenido del curso está en `docs/es/`; esa versión es la referencia para las traducciones. La portada del repositorio solo enlaza a los índices de cada idioma.

Al proponer una lección o corregir una existente:

- Mantén las lecciones cortas y centradas en un objetivo práctico.
- Conserva el orden y la numeración de los módulos entre idiomas.
- Comprueba los enlaces y las imágenes después de mover archivos.
- Presenta las preguntas de práctica como material original y no oficial. Cuando se elija una certificación, relaciona cada pregunta con un objetivo público y añade una explicación de la respuesta.

Para añadir un idioma, crea una carpeta bajo `docs/` con su código ISO 639-1, incluye un `README.md` y traduce las lecciones y la autoevaluación manteniendo su numeración.

## English

The course source is in `docs/es/`; use it as the reference for translations. The repository landing page only links to each language index.

When adding or editing a lesson:

- Keep lessons short and focused on a practical learning objective.
- Preserve module order and numbering across languages.
- Check links and images after moving files.
- Keep practice questions original and clearly unofficial. Once a certification is selected, map each question to a public objective and explain the answer.

To add a language, create a folder under `docs/` using its ISO 639-1 code, add a `README.md`, and translate the lessons and self-assessment while preserving their numbering.
